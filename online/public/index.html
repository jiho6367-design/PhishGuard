      이 브라우저의 분석 요약

      저장하지 않으면 현재 탭을 닫거나 새로고침할 때 사라집니다.

      제목·발신자·점수도 민감한 정보일 수 있습니다. 본문·전체 URL·첨부 파일명·원문 근거는 이력에 저장하지 않습니다. 같은 브라우저 프로필의 다른 탭과 사용자는 저장된 요약을 볼 수 있습니다.

      0개 · 최대 50개 / 7일

      7일이 지난 요약은 앱을 열거나 이력을 조회·저장할 때 삭제됩니다. 브라우저를 닫아 둔 동안 자동 삭제되지는 않습니다.

      이 브라우저의 설정

      서버의 공유 설정을 바꾸지 않습니다. 적용된 임계값은 다음 분석부터 사용합니다.

      20 / 100

      위험지수가 임계값 이상이면 ‘검토 필요’로 표시합니다. 낮출수록 작은 신호도 검토 대상으로 표시합니다.

      기본은 저장하지 않음입니다. 처음 켜면 앞으로 분석하는 요약부터 저장하며, 이전에 현재 탭에서만 표시한 이력을 복사하지 않습니다. 본문·별도 링크 목록·첨부 파일명·원문 근거는 저장하지 않습니다. 제목·발신자에서는 알려진 주소 형식의 전체 URL을 제외하지만 일반 도메인이나 비정형 정보를 완전히 제거하지 못하며 제목·발신자 자체도 민감할 수 있습니다. 최대 50개, 7일을 유지합니다.

      공용 PC에서는 선택하지 마세요. 저장은 암호화된 개인 계정 보관함이 아닙니다. 같은 브라우저 프로필의 다른 사용자·확장 프로그램이 접근할 수 있습니다.

      체크를 해제해 적용하면 저장된 이력·설정·동의 표시를 모두 삭제합니다. 삭제 완료 전에는 성공으로 표시하지 않습니다.

      분석 범위와 데이터 흐름

      온라인 규칙 분석 모드입니다. 합성 예제를 재생하는 데모와 다릅니다. 사이트의 로그인 보호가 켜져 있으면 같은 주소의 로그인 쿠키를 전송할 수 있으며 해당 호스팅 서비스의 정책이 적용됩니다.

      서버로 보내는 정보

      분석 버튼을 누르면 입력과 임계값을 이 사이트의 서버에 보냅니다. 요청은 앱 코드에서 캐시하지 않으며 서버 DB·메일 연결·서버 이력·공유 설정 기능을 제공하지 않습니다.

      취소는 화면의 대기와 저장을 중지합니다. 이미 전송된 요청을 서버에서 되돌리거나 로그에서 삭제하는 기능은 아닙니다.

      텍스트만 검사합니다

      외부 AI API 호출, URL 방문, 첨부 파일 실행, Gmail 접근을 하지 않습니다. 실제 링크의 접속 결과나 악성 파일 내부를 검증하지 못합니다.

      인증 결과는 사용자가 알고 있는 값을 입력합니다. 낮은 지수도 발신자와 요청을 직접 확인해야 합니다.

      이 브라우저에만 저장

      선택한 경우 IndexedDB에 요약과 설정을 저장합니다. 다른 브라우저 프로필과 공유하지 않습니다. 같은 프로필의 탭은 공유합니다. 사이트 주소(출처)가 바뀌면 브라우저 저장소도 분리되며 이력이 자동 이전되지 않습니다.

      저장이 차단되거나 용량이 부족해도 분석은 가능합니다. 삭제 실패 시 기존 데이터가 남아 있을 수 있으므로 브라우저의 사이트 데이터 삭제 기능도 확인하세요.

      호출 한도와 운영 한계

      본문 16,000자, 요청 64KiB, URL 50개, 첨부 파일명 20개로 제한됩니다. 과도한 요청은 잠시 기다린 뒤 재시도해 주세요.

      서버의 요청 제한은 인스턴스별 메모리 기준입니다. 서버리스의 재시작·여러 인스턴스에서 전체 사용량을 영구적으로 보장하지 못합니다. 무료 호스팅 한도·로그·접근 보호는 배포 운영 설정에 따릅니다.

      PhishGuard · 근거를 확인하고, 공식 경로로 다시 확인하세요.

      이력·설정을 모두 삭제할까요?

      이 브라우저 프로필의 저장된 요약·설정·저장 동의와 현재 탭의 이력을 삭제합니다. 임계값은 20으로, 저장은 꺼짐으로 돌아갑니다. 다른 탭의 이미 표시된 결과는 해당 탭에서 비우거나 닫아 주세요.
